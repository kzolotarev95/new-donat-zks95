# Двухфакторная защита администратора

После обновления откройте **Настройки → 2FA**, сразу под Google reCAPTCHA.

1. Подтвердите текущий пароль и нажмите **Подключить 2FA**.
2. В Google Authenticator, Microsoft Authenticator, 2FAS или другом приложении TOTP отсканируйте QR-код. Он создаётся локально на сервере, без отправки секрета внешнему сервису. Можно ввести показанный ключ вручную: TOTP, 6 цифр, период 30 секунд.
3. Введите код приложения и нажмите **Подтвердить и включить 2FA**. Настройка действительна 10 минут; до подтверждения защита не включается.
4. Сохраните 10 резервных кодов в менеджере паролей или распечатайте. Они показываются только один раз. Кнопка **Скачать коды** сохраняет текстовый файл на устройстве.

При следующем входе сначала вводятся логин, пароль и reCAPTCHA, если она настроена. Затем появляется отдельная форма для кода приложения. Без второго шага платежи, настройки, бэкапы и API администратора недоступны. Подтверждение входа действительно 5 минут.

Каждый код приложения работает только один раз, в том числе при включении или изменении защиты. Если вы только что использовали код, дождитесь следующего. Период — 30 секунд; допускается расхождение часов на один период. Включите автоматическую дату и время на телефоне и синхронизацию времени VPS (`timedatectl status`).

## Если потерян телефон

После ввода пароля нажмите **Использовать резервный код**. Каждый резервный код также работает только один раз. После входа можно отключить 2FA и привязать новое приложение либо выпустить новые резервные коды. Эти операции требуют текущий пароль и код приложения или неиспользованный резервный код. Старые резервные коды при перевыпуске аннулируются.

Если потеряны и приложение, и резервные коды, восстановление через публичную форму входа не предусмотрено. Владелец VPS может выполнить через SSH:

```bash
sudo /opt/new-donat-zks95/.venv/bin/python /opt/new-donat-zks95/scripts/admin_security.py reset-2fa
```

Команда запросит логин и подтверждение, создаст защищённую копию базы и `.env`, отключит 2FA только для выбранного аккаунта и завершит его сеансы. Пароль сохранится. Затем войдите и подключите 2FA заново. Обычный сброс пароля через `scripts/create_admin.py` не отключает 2FA. [Полный справочник команд](ADMIN.md).

## Хранение и ограничения

- Секреты приложения хранятся в SQLite зашифрованными с помощью `APP_SECRET_KEY`. Резервные коды хранятся только в виде SHA-256 хешей случайных 80-битных значений. Секрет и коды не помещаются в cookie, журналы или GitHub.
- Коды потребляются атомарно, чтобы два процесса Gunicorn не могли принять один код одновременно. Лимиты попыток также общие для процессов и сохраняются при перезапуске: 5 попыток второго фактора за 5 минут, 10 попыток пароля на логин и 60 на адрес за 5 минут. Успешная проверка очищает соответствующий лимит аккаунта. Адрес берётся из соединения приложения, а за локальным Nginx — из перезаписываемого им `X-Real-IP`. Произвольному `X-Forwarded-For` приложение не доверяет.
- После включения/отключения защиты, перевыпуска резервных кодов или изменения учётных данных остальные сеансы завершаются. Уже открытый сеанс не позволяет обойти вновь включённую 2FA.
- Страницы администратора и QR-коды отдаются с `Cache-Control: no-store`, без передачи Referer и с запретом встраивания во фрейм.
- 2FA привязана к учётной записи администратора. JSON-бэкапы сайта не экспортируют и не перезаписывают учётные записи, секреты 2FA или резервные коды. Для полного восстановления именно доступа администратора нужны защищённая копия SQLite и соответствующий `APP_SECRET_KEY` из `.env`. Смена этого ключа без подготовки делает зашифрованные секреты недоступными; 2FA при этом не отключается.
- Используйте HTTPS. TOTP защищает вход, но не заменяет защиту VPS, надёжный пароль и конфиденциальность резервных копий.
- В production админка не открывается с `APP_SECRET_KEY` короче 32 символов. Установщик генерирует случайный ключ автоматически. Для существующей установки сохраняйте текущий надёжный ключ; не меняйте его после подключения 2FA без подготовки миграции секретов.

Алгоритм реализован через [PyOTP](https://pyauth.github.io/pyotp/), QR-код — через [python-qrcode](https://github.com/lincolnloop/python-qrcode).
