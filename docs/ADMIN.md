# Администрирование ZKS95 Developer

Откройте «Аккаунт» → «Мануал команд»: категории раскрываются и закрываются, у команд есть кнопка копирования. Все команды выполняются через SSH на VPS.

## Входы и сеансы

В «Аккаунт» отображаются успешные входы: IP, время UTC, устройство, способ подтверждения и последняя активность (обычно обновляется не чаще раза в минуту). Устройство запоминается автоматически только после полного входа, включая 2FA, если она включена. Подписанная cookie и серверный сеанс действуют до 10 лет бездействия и продлеваются при использовании; закрытие браузера, перезапуск приложения и обновление сайта не завершают вход. Пароли и секрет 2FA в cookie не сохраняются. Cookie защищена HttpOnly, SameSite=Lax и Secure в production.

Можно завершить отдельный или все другие сеансы. «Выйти» отзывает серверный сеанс: даже копия старой cookie после этого не даст войти. Смена пароля, логина и параметров 2FA завершает остальные сеансы. Ещё действующие сеансы прежней версии получают новый срок при следующем посещении; истёкшие и отозванные сеансы не восстанавливаются и потребуют входа один раз.

Safari, приложение с экрана «Домой» и браузер Telegram могут хранить отдельные cookie, поэтому в каждом из них нужно войти отдельно. Удаление cookie, приватный режим или ограничения браузера также могут потребовать нового входа. Используйте тот же домен; cookie разных доменов не объединяются. Внешний IP может меняться — сам по себе переход между Wi-Fi, мобильной сетью и VPN не завершает сеанс.

IP берётся из X-Real-IP только от локального reverse proxy, который обязан перезаписывать этот заголовок. Стандартная конфигурация Nginx проекта это делает. Заголовки от удалённых клиентов не принимаются. Геолокация и внешние сервисы определения IP не используются.

## Push о входах

В «Уведомления» включите общую отправку и «Оповещать о входах в панель». Настройте VAPID и подключите хотя бы одно устройство. Проверьте кнопку тестового push. На iOS разрешение запрашивается в приложении, добавленном на экран «Домой». При полном успешном входе (после 2FA, если она включена) создаётся уведомление с логином, IP, устройством и временем. Неудачный вход или только проверенный пароль не создают уведомление.

Отправка выполняется в фоне через очередь SQLite и не задерживает вход. Таймер new-donat-zks95-login-push.timer повторяет доставку после временных ошибок примерно раз в минуту, до трёх попыток. При завершении фонового процесса задание вернётся в работу после истечения 10-минутной аренды. Отключение оповещений отменяет ожидающие задания. Web Push зависит от разрешения браузера, сети и сервиса доставки устройства; гарантировать получение на выключенном или отключённом устройстве нельзя.

## Справочник SSH-команд

### Состояние и журналы

**Статус панели** — Показывает состояние сервиса и последние сообщения.

```bash
sudo systemctl status new-donat-zks95 --no-pager
```

**Проверка приложения** — Проверяет backend на VPS; ожидается HTTP 200. Если backend отвечает, отдельно проверьте Nginx, DNS и сеть.

```bash
curl -fsS --connect-timeout 2 --max-time 5 http://127.0.0.1:8015/healthz
```

**Последние сообщения** — Последние 100 записей приложения. Перед отправкой журналов другим людям удалите личные данные.

```bash
sudo journalctl -u new-donat-zks95 -n 100 --no-pager
```

**Журнал в реальном времени** — Новые сообщения сервиса. Остановить просмотр — Ctrl+C.

```bash
sudo journalctl -u new-donat-zks95 -f
```

**Автозапуск и таймеры** — Автозапуск панели, контроль работоспособности и повторная доставка уведомлений о входах.

```bash
sudo systemctl is-enabled new-donat-zks95
sudo systemctl list-timers 'new-donat-zks95-*' --all --no-pager
```

### Восстановление доступа

**Состояние защиты** — Список аккаунтов, состояние 2FA и число активных сеансов. Секретные ключи не выводятся.

```bash
sudo /opt/new-donat-zks95/.venv/bin/python /opt/new-donat-zks95/scripts/admin_security.py status
```

**История входов через SSH** — Запросит логин и покажет последние 50 входов: время UTC, IP и браузер.

```bash
sudo /opt/new-donat-zks95/.venv/bin/python /opt/new-donat-zks95/scripts/admin_security.py sessions
```

**Отключить 2FA** — Если потерян телефон и резервные коды: запросит логин и подтверждение, сохранит бэкап, отключит 2FA и завершит все сеансы этого аккаунта. Пароль сохранится. После входа подключите 2FA заново.

```bash
sudo /opt/new-donat-zks95/.venv/bin/python /opt/new-donat-zks95/scripts/admin_security.py reset-2fa
```

**Сбросить пароль** — Запросит логин, подтверждение и новый пароль дважды. Символы пароля в терминале не отображаются. Сохранит бэкап и завершит сеансы. Включённая 2FA сохранится.

```bash
sudo /opt/new-donat-zks95/.venv/bin/python /opt/new-donat-zks95/scripts/admin_security.py reset-password
```

**Завершить все сеансы** — Отзовёт доступ на всех устройствах выбранного аккаунта, включая текущее. Пароль и 2FA сохранятся. Требует подтверждения и сохраняет бэкап.

```bash
sudo /opt/new-donat-zks95/.venv/bin/python /opt/new-donat-zks95/scripts/admin_security.py revoke-sessions
```

### Обновление и управление

**Обновить сайт** — Загрузит изменения из GitHub, обновит зависимости и проверит запуск. При ошибке предусмотрен откат. Настройки и платежи сохраняются.

```bash
sudo /opt/new-donat-zks95/update.sh
```

**Перезапустить панель** — Перезапускает только приложение ZKS95. Возможен короткий перерыв в доступности; другие сайты не затрагиваются.

```bash
sudo systemctl restart new-donat-zks95
```

**Восстановить автозапуск** — Включает запуск панели после перезагрузки и запускает её сейчас.

```bash
sudo systemctl enable --now new-donat-zks95
```

**Проверить Nginx** — Сначала проверит конфигурацию. Перезагрузка настроек произойдёт только при успешной проверке.

```bash
sudo nginx -t && sudo systemctl reload nginx
```

**Редактировать конфигурацию** — Открывает .env в редакторе. После изменения перезапустите панель. Не публикуйте содержимое этого файла.

```bash
sudoedit /etc/new-donat-zks95/.env
```

### Бэкапы и перенос

**Бэкап базы и конфигурации** — Создаёт согласованный снимок SQLite, включая данные WAL, и копию .env в закрытом каталоге /var/backups/new-donat-zks95/security. Путь покажет команда. Бэкап содержит секреты.

```bash
sudo /opt/new-donat-zks95/.venv/bin/python /opt/new-donat-zks95/scripts/admin_security.py backup
```

**Перенос через панель** — В настройках → «Бэкап и перенос» можно скачать или загрузить донатеров отдельно либо полный экспорт настроек и платежей. Экспорт из панели не переносит аккаунты, историю сеансов и секреты 2FA.

**Проверить резервные копии** — Покажет каталоги резервных копий. Для обычного переноса используйте импорт в настройках. Базу вручную восстанавливайте только при остановленном сервисе.

```bash
sudo ls -lh /var/backups/new-donat-zks95
```

### Уведомления

**Повторная доставка push о входах** — Обработает очередь сейчас. Не создаёт тестовое уведомление: для теста используйте раздел «Уведомления».

```bash
sudo systemctl start new-donat-zks95-login-push.service
```

**Журнал отправки push** — Диагностика повторной доставки уведомлений о входах.

```bash
sudo journalctl -u new-donat-zks95-login-push.service -n 50 --no-pager
```

**Включить таймер отправки** — Включает проверку очереди примерно раз в минуту. В панели также должны быть включены push и оповещения о входах.

```bash
sudo systemctl enable --now new-donat-zks95-login-push.timer
```

### VPS и HTTPS

**Диск и память** — Проверяет свободное место и память VPS.

```bash
df -h
free -h
```

**Открытые порты** — Процессы, слушающие TCP-порты: Nginx, backend и другие сервисы.

```bash
sudo ss -lntp
```

**Сертификаты HTTPS** — Если установлен Certbot: покажет сертификаты и сроки их действия.

```bash
sudo certbot certificates
```

**Проверить продление HTTPS** — Если HTTPS настроен через Certbot: тестовое продление без замены рабочего сертификата.

```bash
sudo certbot renew --dry-run
```

**Удалить только этот проект** — Запросит REMOVE, сохранит базу и .env и удалит компоненты проекта. Nginx и сертификаты не удаляются. Используйте только если хотите удалить сайт.

```bash
sudo /opt/new-donat-zks95/uninstall.sh
```

## Восстановление доступа через SSH

admin_security.py запускается только root через sudo, читает /etc/new-donat-zks95/.env и не создаёт пустую базу, если рабочая база отсутствует. Для изменения запрашиваются существующий логин и точная фраза подтверждения. Перед изменением создаются согласованный SQLite-бэкап и копия .env с правами 600 в каталоге с правами 700. Сброс 2FA удаляет текущий и ожидающий ключи и резервные коды только выбранного аккаунта. Все его сеансы и незавершённые проверки входа становятся недействительными. Сброс пароля сохраняет включённую 2FA. Пароли, ключи и коды не передаются аргументами команды и не выводятся в справочнике.

Для восстановления полного снимка site.db и .env остановите сервис, сохраните текущие файлы и используйте согласованную пару базы и .env из одного бэкапа: APP_SECRET_KEY нужен для расшифровки настроек и ключей 2FA. Обычный экспорт из панели предназначен для переноса донатеров, настроек и платежей, без аккаунтов и истории входов.
