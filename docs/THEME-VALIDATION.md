## Автоматические проверки

Полный запуск `python -m pytest -q`: **178 passed**. В набор входят:

- Red / Black по умолчанию и переключение в обе стороны через авторизованную форму;
- защита изменения настроек с помощью существующей авторизации и CSRF;
- сохранение секретного платёжного ключа при выборе темы;
- перенос темы в полном бэкапе и возврат к классической теме при неизвестном значении;
- отображение публичных и административных страниц в обеих темах;
- реальные данные донатеров, закрепление, сумма, ссылка и раскрытие после 12 записей;
- быстрые суммы в пределах настроенных ограничений;
- создание платежа в обеих темах, передача суммы, никнейма и сообщения, запрос СБП, обработка webhook с проверкой статуса и страница успешного платежа.

Платёжные тесты используют подмену официального SDK: реального списания и тестовых записей в рабочей базе не выполняется. Это проверяет интеграцию приложения; фактическое завершение платежа банком не воспроизводилось.

Дополнительно проверяются компиляция Python, синтаксис обоих JavaScript-файлов и отсутствие ошибок пробелов в Git diff.

## Проверка в браузере

Проект запущен локально с отдельной временной SQLite и локальными тестовыми записями, которые не попадают в рабочий сайт.

- Проверены ширины **1920, 1600, 1440, 1366, 1024, 768, 390 и 320 px**; горизонтальной прокрутки нет.
- Исправлено наложение иллюстрации на текст в планшетной ширине.
- Проверены переключение и сохранение обеих тем через админку.
- Проверены быстрые суммы, произвольная сумма, никнейм, счётчик сообщения и возврат кнопки в рабочее состояние при ошибке платёжного API.
- Проверено раскрытие полного списка донатеров и закрытие мобильного меню после перехода.
- Страницы услуг, контактов, реквизитов, конфиденциальности, условий, проектов и результата платежа проверены в мобильной ширине; длинный заголовок конфиденциальности переносится.
- В консоли страницы доната не обнаружено ошибок и предупреждений JavaScript.
- Для уменьшения движения CSS отключает анимации и переходы, а JS пропускает анимации появления при `prefers-reduced-motion`.

Проверка адаптивности проводилась в браузере Chromium с изменением размеров viewport. Отдельное физическое устройство iOS/Android не использовалось.

## Ресурсы и данные

Дополнительные библиотеки отсутствуют. Иллюстрация SVG занимает около 5,5 КБ, отдельный JS темы — менее 1 КБ. CSS новой темы загружается только в Premium Cyber. Все изображения интерфейса локальные, существующая загрузка шрифтов сохранена.

В рабочий сайт не добавляются вымышленные донатеры, суммы, даты, аватары или платежи. Юридические реквизиты доступны по прежнему `/requisites`, новая тема включает ссылку в футере.
