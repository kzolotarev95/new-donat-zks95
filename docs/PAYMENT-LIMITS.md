# Минимальная и максимальная сумма доната

Откройте **Админка → Платежи → Суммы платежей**. Установите минимум и максимум ползунками либо введите числа рядом. Например: минимум **1 ₽**, максимум **100 000 ₽**. Нажмите **Сохранить лимиты**.

- Доступны целые значения от 1 до 1 000 000 ₽. Минимум может совпадать с максимумом, но не может быть больше него.
- При пересечении ползунков соседняя граница сдвигается вместе с выбранной. На сервере оба значения дополнительно проверяются.
- После сохранения новая форма доната, её быстрые кнопки и сервер создания платежа используют одинаковый диапазон. Сумма по умолчанию также укладывается в него.
- Уже созданные платежи и история транзакций не меняются. Старую открытую страницу доната можно обновить; сервер в любом случае проверяет новые лимиты.
- Перезапуск VPS или приложения не нужен. Значения хранятся в SQLite, сохраняются после обновлений и входят в полный бэкап настроек.
- До первого сохранения используются `PAYMENT_MIN_AMOUNT` и `PAYMENT_MAX_AMOUNT` из `.env`. Настройка через админку имеет приоритет.

Две границы записываются одной транзакцией и читаются одним запросом, чтобы одновременно открытая форма не увидела половину обновления. Если импортирован некорректный диапазон, создание платежей блокируется; восстановите допустимые значения через вкладку «Платежи».

## Способ оплаты

Платежи создаются через API ЮKassa с параметром `payment_method_data.type=sbp`. Поэтому после кнопки «Перейти к оплате» открывается сразу защищённый сценарий СБП, без общего списка способов оплаты. Возврат и webhook остаются прежними. Реальный переход проверяется только тестовым платежом в кабинете ЮKassa; тесты проекта не отправляют деньги и не используют секреты.
