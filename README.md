# ZKS95 Developer

Production-ready персональный портал разработчика с GitHub API, приёмом поддержки.
**Стек:** Flask 3 · SQLite (WAL) · Gunicorn · Nginx · systemd · SDK · GitHub Actions.

Доступны две темы: существующая **Red / Black** и новая **Premium Cyber**.
Выбор: **Админка → Настройки → Темы сайта** (под «Глобальным эффектом») → **Сохранить настройки**.
Тема применяется для всех посетителей после обновления страницы; по умолчанию сохранён Red / Black.

[Настройка и устройство тем](docs/THEMES.md) · [Отчёт о проверке и список изменённых файлов](docs/THEME-VALIDATION.md).
