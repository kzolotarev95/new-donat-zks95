# ZKS95 Developer

Production-ready персональный портал разработчика с GitHub API, приёмом поддержки.
**Стек:** Flask 3 · SQLite (WAL) · Gunicorn · Nginx · systemd · SDK · GitHub Actions.

Двухфакторная защита входа настраивается в **Админка → Настройки → 2FA**, под Google reCAPTCHA. Поддерживаются приложения TOTP, QR-код и одноразовые резервные коды. [Подключение и восстановление доступа](docs/2FA.md).

В **Аккаунт** доступны история входов (время, IP, устройство), завершение сеансов и раскрывающийся мануал SSH-команд. Push об успешном входе включается в **Уведомлениях**. [Команды, бэкапы и сброс 2FA через SSH](docs/ADMIN.md).

В **Настройки → Резервный HTTPS-порт для VPS**, под 2FA, можно включить и отключить доступ к сайту и админке через **8443**. Применение выполняет отдельная системная служба с проверкой Nginx и откатом. Настройка сохраняется после обновлений и использует текущий домен/сертификат сайта. [Настройка резервного порта](docs/HTTPS-RESERVE.md).
