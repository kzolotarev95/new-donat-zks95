# ZKS95 Developer

Production-ready персональный портал разработчика с GitHub API, приёмом поддержки.
**Стек:** Flask 3 · SQLite (WAL) · Gunicorn · Nginx · systemd · SDK · GitHub Actions.

Минимальную и максимальную сумму доната можно изменить в **Админка → Платежи → Суммы платежей**. Доступны ползунки и точный ввод; изменения применяются после сохранения без перезапуска. [Инструкция по лимитам платежей](docs/PAYMENT-LIMITS.md).
